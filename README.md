## 📂 Project Structure

### 🔹 1. Basics

Covers fundamental Java concepts and simple exercises:

- **Loops** → Iteration examples  
- **Conditions** → If/else problems  
- **Strings** → String handling and `StringBuilder`  
- **Math** → Mathematical computations (Prime, Palindrome, Series, Sin)  
- **Arrays** → Searching and array manipulation  
- **Input/Output** → Formatting and user input  
- **Exceptions** → Error handling and file operations  
- **Mini Projects** → Simple applications like:
  - BMI Calculator  
  - Salary Calculation  
  - Apartment management

## ▶️ How to Run

Open the folder in an IDE (IntelliJ, Eclipse or VS Code) and run the class that has `main()`.

For a single file, Java 11+ can run it directly:

```bash
java basics/math/Prime.java
```
